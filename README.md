# Rent-a-car 2.0

C# WinForms / .NET Framework 4.7.2, 64-bitni Access ACE drajver. Otvorite TVP Projekat2 2.0/TVP Projekat2 2.0.sln i F5. Izvršna verzija: bin/Release/TVP Projekat2 2.0.exe.

Vozila, kategorije, klijenti, rezervacije, filteri i statistika. Najam traje najmanje jedan sat; naplaćuje se svaki započeti sat.

Demo baza je nova, napravljena iz šeme i izmišljenih podataka. Build je kopira pored programa samo ako radna baza ne postoji. Postojeća radna i originalna baza nisu menjane. Ne objavljivati radnu bazu. Repozitorijum treba da sadrži samo demo/RentACarDB.accdb. Izvor za ponovno pravljenje demo baze je demo/CreateDemoDatabase.cs (kompajlirati kao x64 konzolni program sa referencom System.Data.dll).

Lokalni školski projekat, bez zaštite od paralelnog rezervisanja na više računara. Testovi su u tests; privremeni izlazi nisu deo izvora.
